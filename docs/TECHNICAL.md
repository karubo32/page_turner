| 項目 | 内容 |
|------|------|

## 1ページめくりの動作

| 順 | 動作 | 内容 |
|----|------|------|
| 1 | `tapMotion()` | Z軸でページに触れて持ち上げる |
| 2 | `yMotion()` | Y軸でページを剥がしてめくる（末尾でY・Zを同時にホームへ） |
| 3 | `pressMotion()` | めくったページが浮くのでZ軸で押さえる |

## キャリブレーション概要

- **50ページごと**に区間を分けてZ軸の押し付け角度を管理（最大11区間）
- 区間間は線形補間で自動接続
- 設定値はEEPROMに保存（電源OFFでも保持）
- GUIのキャリブテーブルから各区間の角度を直接編集・送信
- 接続時にテーブルの値と総ページ数を**自動取得**

## 詳細設定（ホーム位置・サーボリミット）

GUI 左サイドバーの「⚙ 詳細設定」から変更できます。  
変更内容は Arduino の EEPROM に保存され、電源を切っても保持されます。

| 項目 | 説明 | 初期値 |
|------|------|--------|
| `yhome` | Y軸の待機角度 | 90 |
| `zhome` | Z軸の待機角度 | 90 |
| `ymin` / `ymax` | Y軸の可動範囲 | 45 / 210 |
| `zmin` / `zmax` | Z軸の可動範囲（`zmin` は 0 未満、`zmax` は 180 超も可） | -14 / 190 |
| `pstart` / `pend` | ページ押さえ角度（先頭 / 最終ページ） | 168 / 174 |

リミットは自動動作・手動操作の**すべてに適用**され、サーボの破損を防ぎます。  
`MIN >= MAX` になる変更は拒否されます。

### Z軸を 0° 未満・180° 超へ動かす

Z軸はパルス幅（マイクロ秒）で直接制御しているため、**0° より下・180° より上へも動かせます**。  
`zmin` に負の値、`zmax` に 180 超の値を設定してください（例: `set zmin -14` / `set zmax 190`）。

角度とパルス幅の対応は次の通りで、**400µs（約 −14°）が下限、2510µs（約 190°）が上限**です。

```
 -14° =  400 µs   ← 下限
   0° =  544 µs
 180° = 2400 µs
 190° ≒ 2503 µs   ← 上限は 2510 µs
```

> **注意**: サーボには機械的なストッパーがあります。そこを超えるパルスを与えると
> モーターが動けないまま電流が流れ続け、発熱・ギア破損につながります。
> `z-` / `z+` で少しずつ動かして、実際に止まる位置を確認してから `zmin` / `zmax` を決めてください。

シリアルから直接変更する場合:

```
set              # 一覧表示
set yhome 95     # 変更
```

- Arduino 側: `Servo.h`, `EEPROM.h`（標準ライブラリ）
