# 本めくり装置 — Page Turner

**本のページを自動でめくる装置**です。
本を開いて置いておくと、モーターでページを1枚ずつ持ち上げてめくってくれます。
パソコンの画面からボタンで操作できます。

> このページは、電子工作がはじめての方でも分かるように書いています。
> コマンドや内部のしくみなど詳しい情報は [docs/TECHNICAL.md](docs/TECHNICAL.md) にあります。

---

## どうやってめくるの？

モーター（サーボ）を2つ使っています。

| モーター | 役目 | たとえると |
|---|---|---|
| **Z軸**（上下に動く） | ページに軽く触れて持ち上げる | 指先でページの端をつまむ |
| **Y軸**（横に動く） | 持ち上げたページを横へ払う | 手首を返してページを送る |

1ページは、次の3つの動きでめくります。

1. **触れる** — Z軸の先についた粘着素材でページに触れ、少し持ち上げる
2. **めくる** — Y軸がスイングしてページを反対側へ送る
3. **押さえる** — めくったページが浮かないように、Z軸で軽く押さえる

本は読み進めるほど片側が厚くなるので、ページの位置に合わせてモーターの角度を自動で少しずつ変えています。

## 必要なもの

| もの | 説明 |
|---|---|
| Arduino Nano（互換品でOK） | モーターを動かす小さなコンピューター。USBケーブルでパソコンとつなぎます |
| サーボモーター × 2 | 一般的なホビー用サーボ（PWM制御のもの） |
| サーボ用の電源（5V） | サーボはたくさん電気を使うので、別の電源から取るのがおすすめです |
| USBケーブル | Arduino Nano とパソコンをつなぐもの（データ通信できるもの） |
| パソコン | Windows / Mac / Raspberry Pi のどれか |
| 本を置く台・アーム | サーボを取り付ける土台（自作） |

---

## 配線

| サーボの線 | つなぐ先 |
|---|---|
| Y軸サーボの信号線（だいだい・黄色など） | Arduino の **D9** |
| Z軸サーボの信号線 | Arduino の **D10** |
| サーボの赤い線（+） | サーボ用電源の **+5V** |
| サーボの黒・茶色の線（−） | サーボ用電源の **−（GND）**と、Arduino の **GND** の両方 |

> **ポイント**: サーボ用電源の GND と Arduino の GND は、必ずつないでください。
> つながっていないとサーボが正しく動きません。
> サーボの電源を Arduino やパソコンの USB から取ると、電力が足りずに
> パソコンや Raspberry Pi が再起動することがあります。

## はじめての準備

最初の1回だけ、次の4つを行います。

### 1. USBドライバを入れる（Windows・Mac）

互換品の Arduino Nano の多くは **CH340** という部品で USB 通信をしています。
パソコンが Arduino を認識しないときは、ドライバを入れてください。
→ https://sparks.gogo.co.nz/ch340.html
（Raspberry Pi などの Linux では不要です）

### 2. Arduino にプログラムを書き込む

1. [Arduino IDE](https://www.arduino.cc/en/software) をインストールします。
2. このページ右上の緑色の **Code** ボタン → **Download ZIP** でファイル一式をダウンロードし、展開します。
3. Arduino IDE で `firmware/bookv9/bookv9.ino` を開きます。
   （同じフォルダの他の `.ino` ファイルも自動でタブとして開きます）
4. メニューで次のように選びます。
   - ツール → ボード → **Arduino Nano**
   - ツール → プロセッサ → **ATmega328P (Old Bootloader)**
   - ツール → ポート → Arduino をつないだときに増えたポート
5. **→（書き込み）** ボタンを押します。「書き込みが完了しました」と出れば成功です。

> 書き込みに失敗するときは、プロセッサを **ATmega328P**（Old Bootloader ではない方）に変えて試してください。

### 3. Python を入れる

操作画面は Python というプログラムで動きます。

- **Windows**: [python.org](https://www.python.org/downloads/) からインストールします。
  インストール画面の最初で **「Add Python to PATH」に必ずチェック**を入れてください。
- **Mac**: [python.org](https://www.python.org/downloads/) からインストールします。
- **Raspberry Pi**: 最初から入っています。

### 4. 通信用の部品（pyserial）を入れる

ターミナル（Windows は「コマンドプロンプト」、Mac は「ターミナル」）を開き、次を入力して Enter を押します。

```bash
pip install pyserial
```

Raspberry Pi では代わりに `sudo apt install python3-serial` です（多くの場合、最初から入っています）。

## 使い方

### 操作画面を開く

| パソコン | 開き方 |
|---|---|
| Windows | `launch_windows.vbs` をダブルクリック |
| Mac | `launch_mac.command` をダブルクリック（初回だけ、ターミナルで `chmod +x launch_mac.command` を実行） |
| Raspberry Pi など | ターミナルで `python3 gui/page_turner_gui.py` |

### Arduino とつなぐ

1. Arduino を USB でパソコンにつなぎます。
2. 画面右上の **PORT** で Arduino のポートを選びます。
   - Windows: `COM3` など
   - Mac: `/dev/cu.usbserial-…` など
   - Raspberry Pi: `/dev/ttyUSB0`
   - 見つからないときは **↺** を押すと一覧が更新されます。
3. **Connect** を押します。右の丸が緑になれば接続できています。

接続すると、Arduino に保存されている設定（総ページ数やキャリブレーションの値）が自動で読み込まれます。

### 本をめくる

1. 左の **Total pages** に本の総ページ数を入れて **Set** を押します。
2. 本を開いて装置にセットします。
3. **▶ START** を押すと、めくり始めます。
4. 止めたいときは **■ STOP** です。

| ボタン | できること |
|---|---|
| **▶ START / ■ STOP** | 自動めくりの開始・一時停止 |
| **⌂ HOME** | モーターを待機位置に戻す |
| **Page Jump** | 今のページ番号を指定する（途中のページから始めるとき） |
| **Step Mode → STEP** | 1ページずつめくるモードにする。**▶ Next** で1ページだけ進む |
| **Speed** | めくる速さ（0.1〜5.0。数字が大きいほど速い） |
| **Manual Servo** | 一時停止中に、モーターを手で少しずつ動かす |
| **⚙ 詳細設定** | 待機位置や、モーターが動いてよい範囲を変える |

> 一時停止中は、キーボードの **↑↓** で Z軸、**←→** で Y軸を少しずつ動かせます。

## うまくめくれないとき（キャリブレーション）

本の紙の厚さや硬さによって、Z軸が「どれくらい深くページに触れるか」を調整する必要があります。
これを **キャリブレーション** と呼びます。

- 本を **50ページごとの区間** に分けて、区間ごとに触れる角度を決めます。
- 区間と区間のあいだは、自動でなめらかにつながります。
- 決めた値は Arduino の中に保存され、電源を切っても消えません。

**調整のしかた**

1. 画面右の **Calibration Table** で、調整したい区間の行を見つけます。
2. **Test ▶** を押すと、その区間の角度で1回だけ動きます。
3. うまくいかなければ、ANGLE の数字を変えて **Apply** を押し、もう一度 **Test ▶**。
   - ページに **届かない** → 数字を **小さく**
   - ページを **何枚も持ち上げてしまう** → 数字を **大きく**
   - 行を左右にドラッグしても数字を変えられます。
4. 全部の区間で調整できたら完了です。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| PORT に何も出ない | USB ケーブルが「充電専用」ではないか / CH340 ドライバを入れたか / **↺** を押したか |
| Connect してもログに何も出ない | Arduino にプログラムを書き込んだか / 別のソフト（Arduino IDE のシリアルモニタなど）が同じポートを使っていないか |
| サーボがガタガタ震える・動かない | サーボ用電源の容量は足りているか / GND を Arduino とつないだか |
| パソコンや Raspberry Pi が急に再起動する | サーボの電源を USB から取っていないか（別電源にする） |
| ページを2枚以上めくってしまう | キャリブレーションの数字を少し大きくする |
| ページに届かない | キャリブレーションの数字を少し小さくする |
| モーターがうなる・熱くなる | **⚙ 詳細設定** で動ける範囲（min / max）を狭める。サーボの限界を超えて押し付けるとギアが壊れることがあります |
