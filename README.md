# 本めくり装置 — Page Turner Controller

自動ページめくり装置の制御システムです。  
Arduino Nano (ATmega328P) + サーボ2軸 + Python GUI で構成されます。

---

## GUI の使い方

GUI は、パソコンからボタン操作で本めくり装置を動かすためのアプリです。
ボタンを押すと、Arduino にシリアルコマンドが送られます（どのコマンドが送られたかは画面下の Serial Log で確認できます）。

### 画面構成

```
┌──────────────────────────────────────────────────────────┐
│ ◈ Page Turner Controller        PORT [COM3 ▼] ↺ Connect ● │ ← 接続バー
├──────────────┬───────────────────────────────────────────┤
│ Controls     │ CMD [                         ] Send ↵    │ ← コマンド直接入力
│ Page Jump    ├───────────────────────────────────────────┤
│ Step Mode    │ Calibration Table        Send All  Fetch  │ ← キャリブテーブル
│ Speed        │  slot / ページ範囲 / 現在値 / 設定値        │
│ Manual Servo ├───────────────────────────────────────────┤
│ Calibration  │ Serial Log                         Clear  │ ← 送受信ログ
│ Advanced     │                                           │
└──────────────┴───────────────────────────────────────────┘
     操作パネル
```

### 1. 接続する

1. Arduino を USB で接続します。
2. **PORT** で Arduino のポートを選びます（見つからないときは **↺** で一覧を更新）。
   - Windows: `COM3` など / macOS: `/dev/cu.usbserial-…` など / Linux・Raspberry Pi: `/dev/ttyUSB0`
3. **Connect** を押します。右の丸が緑になり「Connected」と出れば接続完了です。

接続すると、Arduino に保存されている **総ページ数・キャリブテーブル・詳細設定が自動で読み込まれます**。

### 2. 本をめくる（基本の流れ）

1. **Page Jump** の **Total pages** に本の総ページ数を入れて **Set**
2. 本をセットし、今開いているページを **Page Jump** に入れて **Jump**（最初からなら `1`）
3. **▶ START** で自動めくり開始、**■ STOP** で一時停止（もう一度 START で再開）
4. 終わったら **⌂ HOME** でサーボを待機位置に戻す

### 3. 操作パネル（左側）

| カード | ボタン | できること |
|---|---|---|
| **Controls** | ▶ START / ■ STOP | 自動めくりの開始・一時停止 |
| | ⌂ HOME | Y軸・Z軸を待機位置へ戻す |
| **Page Jump** | Jump | 現在のページ番号を指定する（偶数を入れると奇数に補正） |
| | Total pages → Set | 本の総ページ数を設定（10〜9999）。キャリブテーブルの区間数も変わる |
| **Step Mode** | STEP | 1ページずつ進めるモードの ON / OFF |
| | ▶ Next | ステップモード中に1ページだけめくる |
| | ■ OFF | ステップモードを終了 |
| **Speed** | Set | めくる速さを変更（0.1〜5.0、大きいほど速い） |
| **Manual Servo** | Go / Z+ / Z− / Y+ / Y− | サーボを角度指定、または1°ずつ動かす（**一時停止中のみ**） |
| **Calibration** | Reset All Data | キャリブデータを全消去（確認ダイアログあり） |
| **Advanced** | ⚙ 詳細設定 | ホーム位置・可動範囲・押さえ角度を変更する画面を開く |

> **矢印キー**でもサーボを動かせます: **↑ / ↓** = Z軸 ±1°、**← / →** = Y軸 ±1°（一時停止中のみ。入力欄にカーソルがあるときは無効）

### 4. キャリブテーブル（右上）

ページをうまく1枚だけめくれるように、**50ページごとの区間**で Z軸がページに触れる角度を調整する表です。

| 列 | 意味 |
|---|---|
| SLOT | 区間番号 |
| PAGE RANGE | その区間のページ範囲 |
| Z (now) | Arduino に保存されている現在の角度 |
| ANGLE (set) | これから設定する角度（直接入力、または**行を左右にドラッグ**して変更） |
| Apply | その区間の角度を Arduino に送って保存 |
| Test ▶ | その区間の先頭ページの角度で1回だけ動かして確認 |

- **Fetch** … Arduino から最新の値を読み込み直す
- **Send All** … 全区間の設定値をまとめて送信
- 調整の目安: ページに**届かない → 角度を小さく** / **2枚以上持ち上げる → 角度を大きく**（左ドラッグで値が増え、浅くなります）

### 5. 詳細設定（⚙ 詳細設定）

サーボの待機位置や動ける範囲を変更する画面です。値を入れて **適用** を押すと Arduino の EEPROM に保存され、電源を切っても残ります。**↺ 再取得** で現在の値を読み込み直せます。
各項目の意味は下の「[詳細設定](#詳細設定ホーム位置サーボリミット)」を参照してください。

### 6. コマンド入力とログ

- **CMD** 欄にコマンドを入力して Enter（または **Send ↵**）で、ボタンにない操作も直接送れます（例: `help` でコマンド一覧）。
- **Serial Log** には、送ったコマンド（→、オレンジ）と Arduino からの応答（←、緑）が表示されます。**Clear** で消去。

## 1ページめくりの動作

| 順 | 動作 | 内容 |
|----|------|------|
| 1 | `tapMotion()` | Z軸でページに触れて持ち上げる |
| 2 | `yMotion()` | Y軸でページを剥がしてめくる（末尾でY・Zを同時にホームへ） |
| 3 | `pressMotion()` | めくったページが浮くのでZ軸で押さえる |

## キャリブレーション概要

- **50ページごと**に区間を分けてZ軸の押し付け角度を管理（最大11区間）
- 区間間は線形補間で自動接続
- 設定値はEEPROMに保存（電源OFFでも保持）
- GUIのキャリブテーブルから各区間の角度を直接編集・送信
- 接続時にテーブルの値と総ページ数を**自動取得**

## 詳細設定（ホーム位置・サーボリミット）

GUI 左サイドバーの「⚙ 詳細設定」から変更できます。  
変更内容は Arduino の EEPROM に保存され、電源を切っても保持されます。

| 項目 | 説明 | 初期値 |
|------|------|--------|
| `yhome` | Y軸の待機角度 | 90 |
| `zhome` | Z軸の待機角度 | 90 |
| `ymin` / `ymax` | Y軸の可動範囲 | 45 / 210 |
| `zmin` / `zmax` | Z軸の可動範囲（`zmin` は 0 未満、`zmax` は 180 超も可） | -14 / 190 |
| `pstart` / `pend` | ページ押さえ角度（先頭 / 最終ページ） | 168 / 174 |
| `zlift` | タップでページを捕まえたあと持ち上げるZ角度 | 160 |
| `ywiggle` | タップ中にYを揺らす幅（`yhome` から何度下げるか） | 8 |
| `ypeel1` / `ypeel2` / `ypeel3` | めくるときにYが順に通る角度 | 80 / 65 / 50 |
| `ypspeed` | めくる（剥がす）ときのYの速さ [%]（10〜200。50 なら半分の速さ） | 100 |

リミットは自動動作・手動操作の**すべてに適用**され、サーボの破損を防ぎます。  
`MIN >= MAX` になる変更は拒否されます。

### Z軸を 0° 未満・180° 超へ動かす

Z軸はパルス幅（マイクロ秒）で直接制御しているため、**0° より下・180° より上へも動かせます**。  
`zmin` に負の値、`zmax` に 180 超の値を設定してください（例: `set zmin -14` / `set zmax 190`）。

角度とパルス幅の対応は次の通りで、**400µs（約 −14°）が下限、2510µs（約 190°）が上限**です。

```
 -14° =  400 µs   ← 下限
   0° =  544 µs
 180° = 2400 µs
 190° ≒ 2503 µs   ← 上限は 2510 µs
```

> **注意**: サーボには機械的なストッパーがあります。そこを超えるパルスを与えると
> モーターが動けないまま電流が流れ続け、発熱・ギア破損につながります。
> `z-` / `z+` で少しずつ動かして、実際に止まる位置を確認してから `zmin` / `zmax` を決めてください。

シリアルから直接変更する場合:

```
set              # 一覧表示
set yhome 95     # 変更
```
